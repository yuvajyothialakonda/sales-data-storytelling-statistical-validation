## 📌 Project Overview

This project focuses on analyzing retail sales data to uncover meaningful insights that drive effective business decision-making.

By leveraging **Exploratory Data Analysis (EDA)**, **data visualization**, and **statistical hypothesis testing**, the project converts raw data into actionable, data-driven insights.

---

## 🎯 Objectives

* Analyze sales performance across categories, cities, and products
* Identify trends, patterns, and seasonal variations in sales data
* Understand customer purchasing behavior
* Validate insights using statistical techniques

---

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **SciPy (Statistical Testing)**
* **Jupyter Notebook**

## 📊 Exploratory Data Analysis (EDA)

* Performed comprehensive data cleaning and preprocessing
* Handled missing values and duplicate records
* Analyzed distributions of key variables such as sales, profit, and quantity
* Explored category-wise and city-wise performance

---

## 📈 Data Visualization

* Line charts for identifying trends over time
* Bar charts for comparing category performance
* Pie charts for contribution analysis
* Heatmaps for understanding correlations between variables

---

## 📊 Statistical Validation

* Applied **hypothesis testing** to validate analytical insights
* Techniques used:

  * *t-test*
  * *chi-square test*
* Confirmed whether observed patterns are statistically significant

---

## 🔍 Key Insights

* 📈 Sales showed a significant increase during festive months *(Oct–Dec)*
* 🛒 Electronics emerged as the highest revenue-generating category
* 🌆 A few major cities contributed the majority of total orders
* 🔁 Repeat customers demonstrated higher average spending
